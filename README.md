# AI-Based Student Performance Prediction System

## Phase 2 Working Prototype

This project is a Phase 2 prototype of an AI-based student performance prediction system. A user enters student academic information and the system produces an estimated performance level, risk level and recommendation.

## Inputs
- Student name
- Attendance percentage
- Previous exam marks
- Assignment score
- Internal / quiz marks
- Study hours per day

## Output
- Prediction percentage
- Performance category
- Risk level
- Academic summary
- Recommendation
